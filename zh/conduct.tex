\chapter{行为准则}\label{s:conduct} \index{行为准则}

为了营造一个开放、友善的环境，我们作为贡献者和维护者承诺：
让每个人参与我们的项目和共同体时都不受骚扰，
无论其年龄、体型、残障、族裔、性别认同与表达、
经验水平、教育程度、社会经济地位、
国籍、外貌、种族、宗教，还是性身份与性取向。

\section*{我们的标准}

有助于营造积极环境的行为包括：

\begin{itemize}
\item
  使用友善、包容的语言，
\item
  尊重不同的观点和经历，
\item
  得体地接受建设性批评，
\item
  以共同体的最佳利益为重，以及
\item
  对其他共同体成员表现出共情。
\end{itemize}

\noindent
参与者不可接受的行为包括：

\begin{itemize}
\item
  使用性化的语言或图像，以及不受欢迎的性关注或性挑逗，
\item
  捣乱、侮辱/贬损性评论，以及针对个人或政治的攻击，
\item
  公开或私下的骚扰，
\item
  未经明确许可公布他人的私人信息，比如实际地址或电子地址，以及
\item
  在职业环境中会被合理视为不当的其他行为
\end{itemize}

\section*{我们的责任}

项目维护者有责任澄清可接受行为的标准，
并被期望对任何不可接受行为的事例
采取适当、公正的纠正措施。

项目维护者有权也有责任删除、编辑或拒绝
与本行为准则不一致的评论、提交、代码、wiki 编辑、issue 以及其他贡献，
也有权暂时或永久禁止他们认定为不当、有威胁、冒犯或有害的
任何其他行为的贡献者。

\section*{适用范围}

本行为准则既适用于项目空间内，
也适用于个人代表项目或其共同体时的公共空间。
代表项目或共同体的例子包括：
使用项目的官方电子邮件地址、
通过官方社交媒体账号发帖、
或在线上或线下活动中担任受委派的代表。
对项目的代表，可以由项目维护者作进一步界定和澄清。

\section*{执行}

辱骂、骚扰或其他不可接受的行为，
可以通过发送邮件至项目维护者 \texttt{gvwilson@third-bit.com} 进行举报。
所有投诉都会被审阅和调查，
并会得到在当时情形下必要且适当的回应。
项目团队有义务对举报人的身份保密。
具体执行政策的更多细节可能会另行公布。

不真诚遵守或执行本行为准则的项目维护者，
可能会受到项目领导层其他成员决定的暂时或永久性惩处。
