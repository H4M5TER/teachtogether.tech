\chapter*{守则}

\begin{enumerate}

\item 对学生好点：其他都是小事。\\

\item 记住，你不是你的学生{\ldots}\\

\item {\ldots}因为大多数人宁可失败也不愿改变{\ldots}\\

\item {\ldots}而大部分的不可思议，不过是比别人多知道一件事。\\

\item 永远不要一个人教书。\\

\item 毫不犹豫牺牲“真相”以求清晰。\\

\item 让每一个错误都成为一课。\\

\item 记住，没有哪门课能挺过与学生的第一次接触{\ldots}\\

\item {\ldots}因为每门课对老师都太短、对学生都太长{\ldots}\\

\item {\ldots}而且没人会比你更喜欢这门课。

\end{enumerate}
