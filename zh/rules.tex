\chapter*{规则}

\begin{enumerate}

\item 善良：其余都是细节。\\

\item 记住，你不是你的学习者{\ldots}\\

\item {\ldots}大多数人宁可失败也不愿改变{\ldots}\\

\item {\ldots}而九成的魔法，不过是比别人多知道一件事。\\

\item 永远不要独自教书。\\

\item 永远不要迟疑于「牺牲真实以求清晰」。\\

\item 让每一个错误都成为一课。\\

\item 记住，没有哪门课能挺过与学习者的第一次接触{\ldots}\\

\item {\ldots}每门课对老师都太短、对学习者都太长{\ldots}\\

\item {\ldots}而且没人会比你更对这门课感到兴奋。

\end{enumerate}
